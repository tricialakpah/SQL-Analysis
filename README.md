
# Analysis of FIFA World Cup Tournaments Using SQL

## Background

The FIFA World Cup is one of the most celebrated sporting events in the world, which brings together countries from different continents to compete for the most prestigious title in international football. Beyond the excitement of each tournament, the historical data provides an opportunity to understand how the competition has developed over the years.

My interest in this project comes from my passion in football tournaments and a desire to look beyond individual tournament results and use data to understand the trends and patterns that have emerged throughout the history of the FIFA World Cup especially before I developed the passion. By examining information from previous tournaments, I want to understand how the number of participating teams, matches, attendance, host countries, winners, runners-up, and player performances have evolved over time.

While working with the available FIFA World Cup dataset, I discovered that it did not contain information about the 2026 FIFA World Cup. Since the 2026 tournament is important to understanding the most recent stage in the development of the competition, I updated the dataset by adding the available 2026 tournament data. This makes it possible to extend the analysis to the latest tournament and compare it with previous editions.

## Project Focus

The main focus of this project is to **create a relational database from historical FIFA World Cup tournament data and use SQL to explore and analyse the data**.

The project will focus on:

* World Cup tournaments across different years
* Host countries
* Participating teams
* Tournament winners and runners-up
* Number of matches played
* Tournament attendance
* Player goal-scoring performances
* Trends in the growth and development of the tournament
* Comparisons between different periods and participating countries

A major part of the project will also involve designing an **Entity Relationship Diagram (ERD)** to show how the different entities in the World Cup data are related.

## Problem Statement


The problem this project intends to solve is the need to **organise historical World Cup data into a structured relational database that can be queried and analysed using SQL**. By creating related tables and establishing appropriate relationships between them, the data can be used to answer meaningful questions about the tournament.

Also the absence of the **2026 tournament data** from the available dataset which was added to the dataset.

The project will therefore demonstrate how raw historical FIFA World Cup data can be transformed into a structured database and analysed using SQL to uncover useful information, trends, and patterns.

## Project Objective

The main objective of this project is to **create a relational database and an Entity Relationship Diagram (ERD) using FIFA World Cup tournament data, and analyse the data using SQL**.

## Specific Objectives

The project aims to:

1. Organise the FIFA World Cup historical data into a relational database.
2. Identify the main entities and relationships within the dataset.
3. Design an Entity Relationship Diagram (ERD) for the database.
4. Clean and prepare the data for analysis.
5. Include the available 2026 World Cup data in the analysis.
6. Use SQL queries to explore the historical World Cup data.
7. Identify trends in tournament attendance and participation.
8. Analyse the performance of participating countries.
9. Identify the countries that have won the World Cup most frequently.
10. Analyse runner-up performances.
11. Examine player goal-scoring performances.
12. Compare tournament characteristics across different years.
13. Use SQL to answer relevant business and analytical questions from the dataset.

## Key Questions the Project Will Answer

The SQL analysis will explore questions such as:

* How many FIFA World Cup tournaments are represented in the database?
* How many matches have been played across the tournaments?
* How many teams have participated?
* Which country has won the World Cup the most?
* Which countries have finished as runners-up most often?
* Which continents have produced the most World Cup winners?
* Which countries have hosted the World Cup?
* Does hosting the tournament appear to be associated with winning?
* Which World Cup tournaments recorded the highest attendance?
* How has attendance changed over time?
* Who are the top goal scorers?
* How has the number of participating teams changed over the years?
* How has the number of matches changed over time?
* What trends can be identified when comparing earlier tournaments with more recent tournaments?
* What insights can be obtained from including the 2026 tournament data?

## Database and ERD

A key deliverable of this project is the creation of a relational database. The database will organise the World Cup information into appropriate tables based on the entities identified in the dataset.

The **Entity Relationship Diagram (ERD)** will provide a visual representation of these entities and show how they are connected. This will help ensure that the database is properly structured and that relationships between tournaments, teams, players, hosts, and other relevant information can be represented accurately.

## SQL Analysis

SQL will be used as the main analytical tool for querying the database.

The analysis will include queries for:

* Counting records and participants
* Filtering tournaments by year
* Grouping countries and continents
* Ranking successful countries
* Calculating totals and averages
* Comparing tournament years
* Identifying highest and lowest values
* Analysing attendance trends
* Analysing team and player performance
* Joining related tables to answer more complex questions

The goal is not only to retrieve information but also to use SQL to uncover meaningful patterns from the historical data.
